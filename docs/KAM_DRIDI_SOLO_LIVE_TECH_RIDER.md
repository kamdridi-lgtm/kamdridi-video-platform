# KAM DRIDI — SOLO LIVE TECH RIDER

Status: advance / booking version. Final equipment details are confirmed with each venue before show day.

## Show format
- Artist: **KAM DRIDI**
- Performers travelling: **1**
- Performance: **lead vocal performed live** over professionally prepared stereo backing tracks
- Typical set: **4–7 original songs / approximately 20–35 minutes**
- Touring band: **none required**
- Guitar/backline: **none required**
- Changeover: designed to be fast and low-footprint

## Minimum venue requirements
1. Professional PA appropriate to the room.
2. **1 professional vocal microphone** with stand and XLR line to FOH.
3. **1 stereo playback input to FOH** from the KAM DRIDI playback system / laptop rig.
4. **1 stage monitor mix** for KAM DRIDI, or compatible in-ear feed if agreed in advance.
5. Reliable AC power at the performance position for the playback laptop/system.
6. Basic soundcheck / line check before doors or before the set as the schedule permits.

## Playback system
The show is designed around a laptop-based playback system, planned around Ableton Live.

Playback can provide:
- stereo backing tracks;
- song-to-song programmed transitions;
- internal count-ins/cues where required;
- synchronized show control where the venue can support it.

The show does **not** require Internet access for playback. Final show media should be stored locally with backup copies.

## Optional video / screens
If the venue has a projector, LED wall or house video system, KAM DRIDI can prepare synchronized visual material.

Advance requirements to confirm with venue:
- accepted input / connection format;
- resolution and frame rate;
- aspect ratio / screen dimensions;
- whether house video is controlled by venue staff or can follow an artist feed;
- changeover and testing time.

Video is **optional**. The performance can run fully without house screens.

## Optional lighting synchronization
Where the venue and house lighting system permit, the show can be prepared with synchronized lighting cues / show-control triggers from the playback system.

This is optional and must be advanced with the venue lighting operator. KAM DRIDI does not assume direct access to a venue lighting console.

If synchronization is unavailable, the house lighting operator can run the show normally using a simple song/scene cue sheet supplied in advance.

## Audio routing — target configuration
- Output 1–2: stereo backing track to FOH
- Live vocal: venue microphone directly to FOH
- Artist monitor: vocal + backing tracks at comfortable performance balance

Any additional cue output or dedicated in-ear routing will be confirmed only after the final touring audio interface/playback configuration is locked.

## Backup / fail-safe philosophy
The final touring package should include:
- primary Ableton show stored locally;
- duplicate show/session backup;
- exported stereo emergency playback files independent of the main Ableton session;
- backup storage device;
- required audio/video adapters and power supplies.

No booking should depend on optional synchronized video or lighting being available.

## Venue advance — information requested
Please provide before confirmation / advancing:
- venue PA and FOH details;
- available vocal microphones;
- stereo playback input options;
- monitor / in-ear options;
- stage dimensions;
- soundcheck / line-check timing;
- projector / LED screen specifications if available;
- lighting desk / operator information if synchronized lighting is possible;
- local technical contact name and email/phone for show advance.
